## 任务 5.1 落实数据与工具契约（build-contract）

- 行动：准备授权样本、数据清洗和接口替身，固定字段、版本、权限和测试输入。
- 核对问题：合成适配与真实接口之间有哪些差距？
- 预期交付：数据契约与集成记录

### 填写记录

- 状态：已完成
- 责任人：学员（FDE）实现；秦芮（医院信息工程师）提供接口样本并确认
- 证据位置：医疗-010、011、012、013；资料-HIS名单导出（演练样本 v1.0）
- 结论：HIS 只读名单接口以演练样本冻结为数据契约 v1.0；接口替身（fixtures）覆盖正常、缺字段、重复（同住院号不同出院时间）、家属号码、授权缺失五类输入。与真实接口的差距显式记录：①真实 HIS 的字段命名与空值习惯以联调为准；②导出频率（演练为每日一次）在生产中受 HIS 窗口限制；③授权状态字段的更新时延未知，按"缺失即不外呼"处理。

### 交付物：数据契约与集成记录

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 住院号 | string | 是 | 与出院时间联合唯一（医疗-010） |
| 出院时间 | datetime | 是 | 访谈批次锚点 |
| 科室 / 术式代码 | string | 是 | 决定问卷模板版本（医疗-008） |
| 联系人电话 | string | 是 | 患者本人或家属 |
| 联系人类型 | enum | 是 | 本人/家属，家属须标注（医疗-011） |
| 授权状态 | enum | 是 | 已授权/未授权/撤回；非"已授权"不外呼、不录音（医疗-013、014） |
| 随访状态 | enum | 是 | 待随访/进行中/完成/搁置/已升级 |

清洗规则：去重（住院号+出院时间）、授权过滤、最小必要字段外的列全部丢弃（医疗-013）。测试输入与替身存于版本库（演练示例：commit `a41f0c2`，2026-10-10）。

## 任务 5.2 实现业务闭环（build-implement）

- 行动：把硬规则、模型判断、工具调用及人工复核分开，实现输入到输出的完整路径。
- 核对问题：每个输出如何追溯到来源、规则、模型和确认人？
- 预期交付：原型代码与版本说明

### 填写记录

- 状态：已完成
- 责任人：学员（FDE）实现；林亦舟（随访护士）确认工作台可用性
- 证据位置：医疗-004、005、006、008、016、017；版本 v0.9.0（演练示例，2026-10-17）
- 结论：闭环路径"名单 → 排程 → 触达 → 陈述草稿 → 护士确认 → 登记表 + 专科摘要"全部打通。每个输出可追溯：记录行携带名单版本号、命中的规则 ID 或模型提示置信度、护士确认人与时间戳；红旗升级工单携带触发表述原文（医疗-015）。模型输出仅为草稿与提示，任何写入登记表的动作都有护士确认（医疗-009、018）。

### 交付物：原型代码与版本说明

| 模块 | 类型 | 职责 | 人工复核节点 |
|---|---|---|---|
| 排程引擎 | 确定性规则 | 时段（晚间优先）、三次未接搁置、模板版本过滤 | 护士可手工调整当日排程 |
| 触达工作台 | 工具调用 | 外呼辅助、短信、家属协助标注 | 护士执行 |
| 红旗规则引擎 | 规则+模型提示 | 词表匹配 + 模型红旗提示；命中即中断问卷并生成工单 | 专科医生处置，护士执行院内升级流程 |
| 记录草稿服务 | 模型 | 患者陈述 → 结构化草稿 | 护士确认后才写入登记表（医疗-017） |
| 审计留痕库 | 确定性 | 操作/升级/授权三类事件全量留痕 | 质控只读审计 |

## 任务 5.3 实现异常与审计（build-failure）

- 行动：补齐超时、缺数据、冲突、越权、重复请求和降级路径，保存关键审计字段。
- 核对问题：无法可靠完成时怎样停止、转人工并避免重复执行？
- 预期交付：异常处理与审计样例

### 填写记录

- 状态：已完成
- 责任人：学员（FDE）实现；傅景（隐私与质控专员）验收留痕字段
- 证据位置：医疗-004、005、011、013、014、015；异常样例集（演练示例）
- 结论：六类异常路径全部实现并有样例；降级原则是"停不下来就转人工，转不出去就停止并报警"，任何异常路径都产生留痕事件。

### 交付物：异常处理与审计样例

| 异常 | 触发 | 处置 | 防重复执行 | 样例（演练） |
|---|---|---|---|---|
| 接口超时/中断 | HIS 导出失败 | 启用上一版本名单并标记"待补"，超 24 小时转人工 | 名单版本号幂等 | 10-14 演练：切换 v0.9 名单，34 人标记待补 |
| 缺数据 | 术式代码缺失 | 不入排程，转人工清单 | 处理标记落库 | 10-15 演练：3 人转人工 |
| 冲突 | 同一患者两条记录 | 按住院号+出院时间合并并提示护士 | 合并日志 | 10-15 演练：1 例合并 |
| 越权 | 授权状态非"已授权"被纳入外呼 | 拒绝执行并告警 | 请求前置校验 | 10-16 演练：拦截 2 次 |
| 授权撤回 | 患者撤回授权 | 24 小时内停用录音、停止随访、标记历史录音不得用于训练（医疗-014） | 撤回事件全量留痕 | 10-16 演练：1 例撤回处理完成 |
| 重复请求 | 同一排程任务重复提交 | 以（住院号、出院时间、日期）幂等键去重 | 幂等键唯一约束 | 10-17 演练：去重 5 次 |

审计字段：事件类型、时间戳、操作者、名单版本、关联住院号+出院时间、触发原文（红旗类）、处置人与处置结果。
