# 出院随访与患者协作 · MVP 测试方案

> 被测版本：MVP v0.1.0（2026-11-04，`CHANGELOG.md`）
> 被测对象：`backend/`（Python 标准库 http.server + SQLite）、`frontend/`（静态页）、`tools/run_eval.py`（评估集）
> 上游依据：`docs/03-需求定义.md`（REQ-01～06）、`docs/05-构建集成.md`（数据契约 v1.0、六类异常）、`docs/06-测试评估.md`（90 例评估集）、`docs/附录-GitHub对标调研.md` 6.1/8.4（SEC-01～12）
> 已有基线：`tools/run_eval.py` 90 例全部通过；本方案在此基础上补**接口契约、越权、安全、并发与浏览器端**五类当前未覆盖的测试。

## 一、测试目标与范围

### 1.1 目标

1. 证明"AI 不签名、护士确认后才写库"在**所有路径**（含并发、重放、篡改请求体）上都不可绕过（医疗-009）。
2. 证明危险信号能**中断问卷、立即建单、不写登记表**，且口语/方言变体不因否定词误判（REQ-02、医疗-015）。
3. 证明数据不出院：无外联依赖、日志与审计不含明文身份标识、超白名单字段被拒收（医疗-013）。
4. 证明授权/录音生命周期闭合：非"已授权"不外呼不录音、撤回后 24 h 内停用（医疗-014）。
5. 给出可复现的准出证据：命令、样本、缺陷清单、覆盖率数据。

### 1.2 范围内

排程、触达、红旗、问卷与草稿、确认写库、授权撤回、模板签发、审计与链校验、权限矩阵、异常降级、接口健壮性、浏览器端主流程。

### 1.3 范围外

真实 HIS 联调（用 `fixtures/` 替身）、真实外呼通道（MVP 为手工记录触达）、模型推理质量（MVP 用规则+本地替身）、性能压测到生产量级（仅做试点量级验证）、等保测评。

## 三、分层策略

| 层 | 内容 | 方式 | 执行频率 |
|---|---|---|---|
| L0 静态 | 语法、依赖零外联、无硬编码凭据、无 `print` 明文身份 | `python -m compileall`、`grep` 清单、`pip list` 比对 | 每次提交 |
| L1 单元 | 契约清洗、红旗匹配、令牌、哈希链、限流、日志脱敏 | `pytest`/`unittest`（新建 `backend/tests/`） | 每次提交 |
| L2 接口契约 | 25 个 `/api/*` 的入参校验、状态码、错误码、权限 | `requests`/`urllib` 脚本 | 每日 |
| L3 业务闭环 | 名单导入 → 排程 → 呼叫 → 红旗 → 工单 → 草稿 → 确认 → 登记表 | `tools/run_eval.py` + 新增 E2E 脚本 | 每次提交 |
| L4 安全 | 越权、重放、篡改、注入、出网、日志泄漏 | 手工 + 脚本（SEC 表） | 每批次 |
| L5 非功能 | 并发、容量、兼容、可访问性、备份恢复 | 手工 + `concurrent.futures` | 准出前 |
| L6 验收 | 护士/专科医生/质控三角色走查 | UAT 会 + 签字 | 准出前 |

## 十一、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| SQLite 单写锁在并发下 5xx | 并发用例误判 | 连接 `timeout=15` 已设；并发用例先建索引、控制写事务粒度；记录锁等待耗时 |
| 浏览器端无自动化 | UI 用例不可回归 | 先手工；关键路径补 Playwright（可选，不引入运行时依赖） |
| 红旗语料规模小导致召回虚高 | 上线漏报 | 语料扩到 ≥ 120 条，含方言/否定/语义反转；每轮规则变更重跑 |

| 匿名登录无限流、超限返回 403 | 账号枚举与爆破 | 准出前补：按 `IP+账号` 计数、超限 429；EX-08 同步更新 |

| `GET /api/bootstrap` 公开返回全部账号 | 内部人员与角色信息暴露 | 试点内网可接受；若对外开放需改为登录后返回 |
