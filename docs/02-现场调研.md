## 任务 2.2 还原现状流程（discovery-process）

- 行动：画出触发、输入、交接、人工判断、输出及异常路径，在瓶颈处标明责任人。
- 核对问题：理想流程与现场做法有什么差异？哪些判断只能由人完成？
- 预期交付：现状流程图与异常路径

### 填写记录

- 状态：已完成
- 责任人：学员（FDE）绘图；林亦舟（随访护士）、唐映秋（专科医生）核验
- 证据位置：医疗-002、004、005、006、007、008、010、011、016
- 结论：现状为纯人工串行流程，瓶颈有三：①分组与排程靠护士手工，无效拨打（号码失效、上班时段）消耗工时（医疗-004、016）；②记录重复填写，每次 4 分钟（医疗-006）；③红旗识别完全依赖护士个人判断，升级过程无系统留痕（医疗-005、015）。只能由人完成的判断：红旗的最终判定与升级处置（按院内既有流程）、复诊安排、随访记录确认——AI 只能整理与提示（医疗-007、009、018）。

### 交付物：现状流程图与异常路径

```
患者出院
  └─ HIS 导出名单（Excel，无统一访谈 ID → 按 住院号+出院时间 区分重复，医疗-010）
       └─ 护士手工分组（按术式；术式问卷不同，医疗-008）
            └─ 逐个外呼（患者偏好晚间/老年需家属协助，医疗-016）
                 ├─ [异常A] 号码失效/上班/方言 → 三次未接搁置（医疗-004）→ 无跟踪，完成率损失
                 ├─ [异常B] 危险信号（呼吸困难等）→ 停止问卷 → 按院内流程升级（医疗-005）
                 │        └─ [缺陷] 升级过程无系统留痕（医疗-015）
                 └─ 正常完成 → 手工填写随访登记表（含 4 分钟重复记录，医疗-006）
                      └─ 发给专科 → 专科确认 → 必要时安排复诊（医疗-007）
                               └─ [缺陷] 名单含家属号码，联系人身份与授权状态未单独记录（医疗-011）
```

瓶颈责任人：分组排程与外呼——随访护士；升级处置——专科医生+随访护士；数据断层——医院信息工程师；授权与留痕——隐私与质控专员。

### 填写记录

- 状态：已完成
- 责任人：学员（FDE）收敛；傅景（隐私与质控专员）核对材料边界
- 证据位置：医疗-001、003、005、006、012、013、015、017；资料-HIS名单导出、资料-随访登记表、资料-红旗升级流程
